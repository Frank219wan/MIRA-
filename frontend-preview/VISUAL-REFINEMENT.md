# MIRA 视觉精修

## 审查结论

原版 Recipe 以纵向字段列表为主，右侧留白缺少内容支撑；Parsing 的卡片与清单权重相近，当前进度不突出；Home 与上传页的图片、主标题及交互状态欠缺统一的视觉层级。

## 本次实施

- Parsing：深墨色进度主视觉，暖金进度线；阶段区分进行中、已完成和待开始；关键画面保持真实空位，配取景边角与空白关键帧槽。
- Recipe：编辑式两栏布局，右侧为已有妆面参考；步骤时间直接读取动作数据；产品能力拆成标签；操作区域强调；细节仍可展开。移动端恢复单列阅读。
- Home：强化标题主次、主图裁切及图片编号，底部流程以中文作为视觉主层。
- Tutorial Input：统一四种入口选中状态、文件选择和键盘焦点；示例图固定裁切，避免撑高面板；保留原文件与链接校验。
- 全站：共享字级、暖白底色、细线分隔、标签、禁用及 hover 状态；工具库色块增加边缘质感；匹配状态有明确差异；档案页降低卡片感。
- 系统减少动态效果设置同时作用于 CSS 与 Framer Motion 的主要入场动画。

## 结构边界

App.tsx 路由以及 types、services、mocks 与优化前逐文件对比一致。新增 ReferenceImage 为可复用参考图容器（加载失败显示占位），CapabilityTags 仅格式化现有 service 返回的文字，不推断产品色值或新增业务数据。所有图片来自已有 assets，未下载任何新素材。技术示例图、真实关键帧、识别结果保持空位。
